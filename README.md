# Machine Learning Portfolio

A collection of Machine Learning projects and notebooks covering fundamental data science workflows, predictive modeling, and exploratory data analysis (EDA).

## Projects Included

### 1. Hotel Bookings Analysis & Prediction
- **Objective:** Analyze real-world hotel booking patterns and predict cancellations.
- **Techniques Used:** EDA, data cleaning, classification modeling.

### 2. House Price Prediction
- **Objective:** Predict housing prices based on various features using regression models.
- **Techniques Used:** Data preprocessing, feature engineering, and model training.

### 3. Diabetes Prediction Model
- **Objective:** Build a classification model to predict whether a patient has diabetes based on diagnostic measurements.
- **Techniques Used:** Logistic Regression, Random Forest, classification metrics.

## Technologies
- Python
- pandas, NumPy
- scikit-learn
- matplotlib, seaborn
- Jupyter Notebook
