# Hotel Bookings Analysis and Prediction

An exploratory data analysis (EDA) and machine learning project focused on hotel booking data.

## Overview
This project analyzes a real-world dataset of hotel bookings to understand booking patterns, cancellation rates, and customer behavior. It includes data cleaning, extensive visualizations, and the development of predictive models to forecast cancellations.

## Key Objectives
- Perform data cleaning and handle missing values.
- Conduct Exploratory Data Analysis (EDA) to uncover insights (e.g., busiest months, cancellation trends across different hotel types).
- Build machine learning classification models to predict booking cancellations.

## Technologies
- Python
- Jupyter Notebook
- pandas, NumPy for data manipulation
- seaborn, matplotlib for visualization
- scikit-learn for modeling
